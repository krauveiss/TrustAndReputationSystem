# Trust & Reputation System

Backend API для системы репутации, жалоб и модерации пользователей.

##  О проекте

Это pet-проект, в котором я реализовал backend для системы, где пользователи могут взаимодействовать друг с другом, отправлять жалобы и влиять на репутацию. Основная идея - смоделировать систему с ролями (пользователь, модератор, администратор) и автоматическими санкциями при нарушениях. Проект делался для практики построения backend-логики и работы с Laravel.

---

##  Функциональность

- Регистрация и аутентификация пользователей (Laravel Sanctum)
- Система ролей (user / moderator / admin)
- Отправка и обработка жалоб
- Система репутации
- Автоматические санкции:
  - таймауты
  - баны
- Модерация пользователей
- Админские действия:
  - бан / разбан
  - выдача таймаута
  - смена роли
- Логирование действий

---

##  Архитектура

В проекте использовал стандартную структуру Laravel, но старался не сваливать всю логику в контроллеры:

- Controllers — обработка запросов
- Services — основная бизнес-логика
- Middleware — проверки (бан, таймаут и т.д.)
- FormRequest — валидация входящих данных
- API Resources — форматирование ответов
- Custom Exceptions — обработка ошибок
